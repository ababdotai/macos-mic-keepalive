# KeepMicAlive 1.5.1

Mic KeepAlive is now **KeepMicAlive**. The repository, app name, localized display names, control-panel heading and download filenames now use the new name.

- The README shows supported systems separately with an Apple/macOS badge. Current support remains **macOS 14+ on Apple Silicon and Intel**; this rename does not add other operating systems.
- Includes all 1.5.0 features and the AirPods / BlackHole routing fix.
- The internal bundle identifier and preference keys are unchanged to retain existing settings.

## Upgrade

Quit Mic KeepAlive, install **KeepMicAlive.app** in Applications, and remove the old app to avoid duplicate copies. Recheck “Launch at login” if you use it after moving the app. Older release assets retain their original filenames.

The universal DMG, ZIP and SHA-256 checksums are attached. The app is locally signed, not Apple-notarized. BlackHole 2ch remains an optional, separate installation for whisper boost.
