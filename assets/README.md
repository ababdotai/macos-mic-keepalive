# Logo provenance

`logo.png` is the Liquid Glass-inspired static icon generated with the built-in imagegen tool on 2026-11-09. It is used by the README and both application build paths. Alpha transparency is preserved. `icon.json` wraps the flattened artwork in an Icon Composer document. Xcode compiles `Assets.car` for modern macOS and an ICNS fallback for older versions. The microphone highlights are baked into the artwork; the system handles the icon enclosure and appearances. Both build paths use `scripts/build_icon.py`.
