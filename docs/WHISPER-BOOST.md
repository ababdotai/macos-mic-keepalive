# 轻声增强试用与对比测试

这是一版本地试用功能，不是已经验证能提高识别准确率的正式结论。

## 音频路径

真实麦克风 → 可选轻度降噪 → 可选人声清晰 → +6 / +12 / +18 dB 增益与平滑峰值压缩 → BlackHole 2ch → 语音输入法。

本地 DSP，不是 AI 人声分离；无硬静音门，不保存、不上传声音。

- **轻度降噪**：自适应估计持续底噪，逐频段温和衰减，最多约 6 dB。主要针对稳定风扇声、底噪，不能可靠去除键盘敲击、旁人说话，也可能减弱很轻的人声。
- **人声清晰**：80 Hz 高通削弱低频轰鸣，在 2.2 kHz 附近宽带提升约 3 dB；不切掉高频辅音。它不是语音识别，也会增强同频段噪声。
- 两项默认关闭，可单独或同时开启，仅在增强运行时生效。调整选项与增益不会重启麦克风。为了切换时保持连续，增强的处理路径固定增加一个分析窗延迟（BlackHole 48 kHz 时约 21 ms，不是总端到端延迟）。

固定增益也会放大剩余底噪，压缩用于限制过大的峰值，不能恢复耳机已滤掉的轻声。输出仅指定 BlackHole，不修改音乐输出设备。增强时持续收音，因此 AirPods 的双向模式音质变化依然存在。

## 开始测试

1. 将音乐暂时暂停，保持相同环境、佩戴方式和麦克风位置。若有 DJI 接收器，优先用它收音、AirPods 听音乐。
2. 在工具中选真实麦克风并开启普通保活。在语音输入法中选择同一个真实麦克风，作为基线 A。
3. 打开“增强轻声输入”开关。默认 +12 dB，在“轻 / 中 / 强”分段按钮中直接选择 +6 / +12 / +18 dB。确认显示“正在增强 → BlackHole 2ch”。
4. 在语音输入法的麦克风设置中明确改选 **BlackHole 2ch**，作为增强 B。不要将本工具的源设备或系统音乐输出改成 BlackHole。增强模式暂时固定采集源，系统输入变化不会使工具跟随到 BlackHole。
5. 若语音输入法没有独立设备选项，可在 macOS 系统设置中将默认输入改为 BlackHole；工具保持增强模式和原采集源不变。结束时必须将系统输入改回真实麦克风。

## 先确认音频确实经过增强

语音输入法选 BlackHole 后，轻声说一句；再关闭工具的轻声增强、重新发起一次语音输入，此时不应再收到你的声音（前一次录音缓存可能仍有文字）。重新开启轻声增强，应恢复识别。若关闭增强后新一轮仍能识别，语音输入法很可能没有使用 BlackHole；先修正设备选择，不要继续比较强度。

## A/B 比较准确率

基线和增强都保持保活开启，避免将唤醒延迟误当成增益效果。不要刻意改变说话大小声。每句话按 A→B、下一句 B→A 交替，每个条件重复三次：

- 请把这个函数改成异步执行，并补充错误处理。
- 修复登录页面刷新后状态丢失的问题。
- 将请求超时时间设为十五秒，失败后重试两次。
- 今天下午三点半检查测试结果，然后提交代码。
- 请保留原来的接口名称，不要修改数据库结构。

每次把实际识别文字粘到下表；先看漏掉的字和错字，不把标点差异算错误。记录首字丢失、整句无结果、长停顿和重复词。不要只凭一次表现判断。

如果 +12 dB 的结果更差或气声/背景声很突出，试 +6 dB；如果两者都明显漏掉轻声，再试 +18 dB。挑错误最少的一档，而不是声音最大的一档。若没有稳定提升，关闭增强即可。

## 单独比较降噪与人声清晰

始终让语音输入法选择 BlackHole，增益固定 +12 dB，麦克风位置和说话音量不变：

1. 两项都关，轻声读上面的句子，记下漏字和错字。
2. 只开“轻度降噪”，留 1–2 秒环境底噪后再读；检查轻声、首字和尾音是否保留。
3. 只开“人声清晰”再读，注意齿音、气声是否变得刺耳。
4. 两项同时开启再读。每种条件至少重复三次，交替顺序，选择错字最少的组合。

尾音变少先关闭降噪；齿音更重先关闭人声清晰；仍有失真再降低增益。环境本来很安静时，不一定需要降噪。

## 结束与恢复

先把语音输入法（必要时包括系统）的输入切回真实麦克风，再取消轻声增强；不需要保活时再停止保活。若保活开关仍开启，只取消增强会继续普通保活。开启增强会自动开启保活；关闭保活会同时关闭增强。关闭增强会停止向 BlackHole 输出；关闭保活或退出应用时释放麦克风；如果语音输入法仍选择 BlackHole，它将听不到本工具的声音。

普通退出再启动时，增强、降噪及人声清晰默认关闭，强度恢复 +12 dB。通过应用内更新自动重启时，会恢复更新前的采集设备、保活、增强、强度和处理选项，避免 BlackHole 意外断流。

## 工程验证与边界

`make test` 检查增益、静音、峰值限制、重叠相加重建、16/24/44.1/48/96 kHz 频响、低电平信号通过、缓冲块大小无关性、实时切换，以及原有路由/恢复/排序/本地化测试。固定种子合成测试中，稳态噪声降低约 4.5 dB，调制人声频段测试信号的 SNR 从 12.6 dB 到 16.9 dB；这不是录制人声或语音识别评测。

`make test-enhancement-loopback` 是显式的本机集成测试：需要 BlackHole 2ch，向其发送低电平合成音并读取回来，不使用真实麦克风、不播放到系统扬声器。不要同时运行其他向 BlackHole 输出的程序，否则测试信号会被混入。已验证 48 kHz 与 16 kHz 输入经 +12 dB 处理后，BlackHole 读回峰值约为原始的四倍，系统输入/输出选择不变。

2026-11-26 新处理链路验证：离线 DSP、面板行为、本地化测试及 Apple Silicon/Intel 构建通过。首次 48 kHz 实机回环读回 +12 dB 峰值约 0.00193，BlackHole 系统音量为 −6.27 dB，解释了相对原满音量测试约一半的幅度。回环测试已改为与同一路径的 0 dB 校准值比较，不改用户音量。后续完整回环在电脑锁屏、外接麦克风断开的环境中阻塞于 CoreAudio 创建设备流，已停止；新降噪/人声清晰的完整实机回环和真人识别效果尚未验证。测试设有 60 秒超时，避免持续挂起。

这些验证说明增强链路能传递声音，不代表语音输入法识别准确率已经改善；准确率需要上述真人轻声 A/B 测试。

本机真实设备冒烟检查：AirPods Pro 开启增强后，持续采集正常，菜单显示向 BlackHole 输出，未报告路由/格式错误；退出增强恢复普通保活。未对语音输入法识别结果作准确率断言。

## 新版控制面板

点击菜单栏图标打开面板。真实设备优先，虚拟/聚合设备默认折叠；各组按使用频率排序。设备块在本次展开期间保持位置不变，下次打开再应用新排序；设备多时只滚动设备区域。所有内部开关、设备选择、增益、重新检测、帮助和启动设置都留在同一个面板，点击外部或按 Escape 收起。退出应用以及跳转浏览器/系统设置属于离开当前应用的操作。

- 第一张卡片：直接点选两列设备块（当前设备高亮并带对勾），打开“保持麦克风就绪”。关闭时同时关闭增强并释放采集。
- 第二张卡片：打开“增强轻声输入”，选择轻/中/强，可点选“轻度降噪”和“人声清晰”；卡片内说明输入法应选择的设备。开启增强自动开启保活；关闭增强保留普通保活。停止增强后会持续提示将语音输入法切回真实麦克风。
- “启动设置”始终展开，使用勾选卡片；登录启动与恢复上次保活各自独立。增强仍不会跨重启自动恢复。
- 未检测到 BlackHole 时显示“安装组件…”；点击打开官方站点，选择 2ch 安装。完成安装（必要时按安装器提示重启）后，回到面板点击“重新检测”。普通保活不依赖 BlackHole，不捆绑或静默安装驱动。
- macOS 26+ 使用系统玻璃卡片；macOS 14–15 使用原生毛玻璃兼容显示。

面板固定为 380 点宽，展开虚拟设备或帮助只改变高度，超出屏幕空间时滚动。界面语言跟随系统首选语言（英文、简体/繁体中文），重启应用后应用语言变化。

状态栏麦克风右侧：盾牌表示保活正常，上方加粗加号表示增强已运行。等待恢复或断连时显示等待/断连标记，不显示增强正常标记。
