# Logo provenance

`logo.png` is the user-approved black and pearlescent microphone icon generated with the built-in imagegen tool on 2026-11-12. The original PNG is preserved byte-for-byte, including its alpha channel. The README and both application build paths use this asset.

`icon.json` wraps the artwork in an Icon Composer document with a near-black background and a scale fitted to the macOS enclosure. Xcode compiles `Assets.car` for modern macOS and an ICNS fallback for older versions via `scripts/build_icon.py`. Metallic highlights and iridescence are baked into the artwork.
