# KeepMicAlive 1.5.2

## One-click updates

- The header shows the installed version and a check-for-updates button.
- Checks GitHub Releases at launch and every eight hours; wake resumes an overdue check.
- A newer stable release shows an accent-colored download button. Click once to download, verify, install and restart.
- Update restarts resume the selected microphone, keep-alive, boost, gain and voice-processing options. Ordinary launches keep their existing startup preferences.
- ZIP checksums, bundle identity, version and code signatures are checked before installation. The old app is retained until the new process acknowledges startup; failed replacement or startup restores the old bundle.
- Public GitHub API rate limits fall back to the repository's latest-release page. No token is required.

## Quiet speech

- Optional **Gentle denoise** reduces steady background noise with conservative spectral attenuation and no hard noise gate.
- Optional **Voice clarity** cuts low rumble and gently boosts speech presence before gain and peak limiting.
- Gain and processing options change live without restarting the microphone. Both filters default off on ordinary launches.
- These are local DSP filters, not AI speech separation. Speech-recognition improvements remain unproven; compare the same quiet sentence with fixed gain.

## Install

macOS 14+ · Apple Silicon and Intel. Download the universal DMG or ZIP below.

Existing versions without the in-app installer need this first upgrade installed manually. Future updates can use the download button. Keep the app in a writable Applications folder.

The app is locally signed, not Apple-notarized. macOS may require first-launch approval. BlackHole 2ch remains optional and separately installed; no audio is saved or uploaded.
